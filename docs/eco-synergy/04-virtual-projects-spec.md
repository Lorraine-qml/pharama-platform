# 04 虚拟项目 — 功能与界面需求

## 4.1 功能清单

| 功能 | 说明 |
|------|------|
| 列表查看 | 展示所有虚拟项目；支持按**领域**、**状态**、**名称**筛选；支持分页与导出 |
| 新增虚拟项目 | 表单录入 + 保存；关联实体项目可选 |
| 编辑虚拟项目 | 同表单，预填；未关联重要业务时可编辑全部字段（业务规则由后端约束） |
| 删除虚拟项目 | 二次确认；若存在强关联（订单、合同）则接口拒绝并提示 |
| 关联实体项目 | 下拉数据来自**入孵管理**中**实体**类型项目；展示项目名称及编码 |
| 查看详情 | 弹窗或独立档案页：完整字段 + **关联资源使用记录**（V1 可占位表格） |

## 4.2 列表页布局（线框）

- 标题区：`虚拟项目` + 主操作 `[+ 新增虚拟项目]` + `[导出]`  
- 筛选区：`领域` 下拉、`状态` 下拉、`🔍 项目名称` 搜索（实时或防抖）  
- 表格列：`项目名称` | `所属领域` | `资源需求` | `联系人` | `关联实体项目` | `操作`  
- 操作列：`[编辑]` `[删除]` `[详情]`（权限不足时隐藏或禁用）

示例行（示意）：

| 项目名称 | 所属领域 | 资源需求 | 联系人 | 关联实体项目 | 操作 |
|----------|----------|----------|--------|----------------|------|
| 类器官芯片 | 类器官 | 共享实验室、细胞培养箱 | 张三 | - | 编辑/删除/详情 |
| AI药物筛选 | AI制药 | 计算资源、基因测序 | 李四 | 基因治疗项目 | … |

## 4.3 新增 / 编辑弹窗字段

| 字段 | 控件 | 校验 |
|------|------|------|
| 项目名称 | 单行文本 | 必填 |
| 所属领域 | 下拉（可配置字典） | 必填 |
| 资源需求 | 多行文本 | 选填，长度上限建议 2000 |
| 联系人 | 单行文本 | 必填 |
| 联系电话 | 单行文本 | 必填，手机号/固话格式校验 |
| 电子邮箱 | 单行文本 | 选填，邮箱格式 |
| 关联实体项目 | 下拉，首项「无」 | 选项来自入孵实体项目 |
| 状态 | 单选 `● 启用` `○ 停用` | 必填，默认启用 |

底部：`[保存]` `[取消]`；保存成功关闭弹窗并刷新列表；失败 Toast 错误信息。

## 4.4 详情内容（弹窗或档案页）

- 基本信息区：与表单一致字段 + `创建时间` `更新时间` `创建人`  
- 关联实体项目：展示名称、编码、跳转入孵档案（外链）  
- 关联资源使用记录：表格占位（资源类型、资源名称、占用时段、状态），V2 对接真实流水  

## 4.5 数据与枚举

- **领域**：与基础数据字典对齐（或独立字典 `eco.virtual_project.domain`）。  
- **状态**：启用 / 停用；停用后项目方只读可见或不可见（产品二选一，需在接口约定）。  

## 4.6 接口（建议）

- `GET /api/eco/virtual-projects` 分页 + 筛选  
- `POST /api/eco/virtual-projects`  
- `PUT /api/eco/virtual-projects/:id`  
- `DELETE /api/eco/virtual-projects/:id`  
- `GET /api/eco/virtual-projects/:id` 详情含关联摘要  
- `GET /api/eco/linkable-physical-projects` 可关联实体项目下拉  

## 4.7 验收要点

- 筛选、搜索、分页、导出与全局规范一致（见 `09-interaction-pagination-export.md`）。  
- 删除必有二次确认。  
- 无权限用户看不到写操作。
