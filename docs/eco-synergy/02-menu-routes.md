# 02 菜单结构与路由

## 2.1 一级 / 二级菜单（侧边栏）

| 一级菜单 | 二级菜单 | 功能定位 |
|----------|----------|----------|
| 数字孪生空间 | **生态协同 → 虚拟项目** | 管理虚拟入孵项目（不占实体空间），可关联实体项目 |
| 数字孪生空间 | **生态协同 → 外部合作** | 管理 CRO、医院、高校、检测机构等，可关联实体项目 |
| 数字孪生空间 | **生态协同 → AI 能力** | 展示 AI 模型、智能体、Skill 等节点（V1 静态） |
| 数字孪生空间 | **生态协同 → 知识库** | 管理公共/行业/私有知识库，提供访问与管理入口 |

菜单分组标题建议：**「生态协同」**，其下挂上述四个叶子路由。

## 2.2 前端路由（约定）

| 路由 | 页面 |
|------|------|
| `/eco/virtual-project` | 虚拟项目列表（及弹窗内新增/编辑） |
| `/eco/external-partner` | 外部合作列表（及弹窗内新增/编辑） |
| `/eco/ai-ability` | AI 能力列表与详情弹窗 |
| `/eco/knowledge-base` | 知识库列表与新建/编辑弹窗 |
| `/eco/knowledge-base/:libraryId/manage` | 某知识库文档管理（上传、列表、预览/下载/删除） |

可选：`/eco` 重定向至默认子页（如虚拟项目），便于书签 `/eco`。

## 2.3 面包屑

建议：`首页` → `数字孪生空间` → `生态协同` → `{子模块名称}`；文档管理子页在末尾增加 `知识库管理`。

## 2.4 与现有孪生路由关系

- 不改变 `/twin/infrastructure/*`、`/twin/distribution/*` 语义。  
- `/eco/*` 为**并列子域**，在导航上归属同一一级「数字孪生空间」，便于用户心智统一。
