# 03 角色权限矩阵

以下描述**业务期望**；V1 演示环境可放宽为「登录可访问」，但界面需按角色**预留按钮显隐**，便于后续接真实 RBAC。

## 3.1 矩阵总表

| 角色 | 虚拟项目 | 外部合作 | AI 能力 | 知识库 |
|------|----------|----------|---------|--------|
| **超级管理员** | 全部操作 | 全部操作 | 全部操作 | 全部操作 |
| **企业运营** | 增删改查、关联实体项目 | 增删改查、关联实体项目 | **仅查看** | 管理**公共 / 行业**库；私有库按策略扩展 |
| **项目方** | **仅查看自己的**虚拟项目（只读） | **仅查看**（若业务需要可限制为「与本企业相关」） | **仅查看** | **访问**公共库；**访问自己的**私有库 |
| **专家** | **无权限**（隐藏入口或 403） | **无权限** | **仅查看** | **访问**公共库 |

## 3.2 操作级拆解（建议）

### 虚拟项目

| 操作 | 超级管理员 | 企业运营 | 项目方 | 专家 |
|------|------------|----------|--------|------|
| 列表/筛选/导出 | ✓ | ✓ | 仅本人/本企业数据 | ✗ |
| 新增/编辑/删除 | ✓ | ✓ | ✗ | ✗ |
| 关联实体项目 | ✓ | ✓ | ✗ | ✗ |
| 详情/档案 | ✓ | ✓ | ✓（只读） | ✗ |

### 外部合作

| 操作 | 超级管理员 | 企业运营 | 项目方 | 专家 |
|------|------------|----------|--------|------|
| 列表/筛选/导入/导出 | ✓ | ✓ | 查看 | ✗ |
| 新增/编辑/删除 | ✓ | ✓ | ✗ | ✗ |
| 关联实体项目 | ✓ | ✓ | ✗ | ✗ |

### AI 能力

| 操作 | 超级管理员 | 企业运营 | 项目方 | 专家 |
|------|------------|----------|--------|------|
| 列表、详情 | ✓ | ✓ | ✓ | ✓ |
| 刷新 / 同步中台（V2） | ✓ | ✓（V2 可限制） | ✗ | ✗ |
| 调用测试（V2） | ✓ | ✗ | ✗ | ✗ |

### 知识库

| 操作 | 超级管理员 | 企业运营 | 项目方 | 专家 |
|------|------------|----------|--------|------|
| 新建/编辑/删除库 | ✓ | 公共+行业 | 私有（_own） | ✗ |
| 管理文档（进入子页） | ✓ | 公共+行业 | 自有私有库 | ✗ |
| 访问（只读浏览） | ✓ | ✓ | 公共 + 自有私有 | 公共 |

## 3.3 前端实现要点

- 路由守卫：无权限角色访问 `/eco/virtual-project` 等时跳转 403 或工作台。  
- 按钮级：`新增` `编辑` `删除` `导入` `管理` `同步` 等按角色 `v-if` / 策略函数统一封装 `can(role, action, module)`。  
- 列表数据：项目方虚拟项目列表接口需带 `tenantId` / `userId` 过滤。
