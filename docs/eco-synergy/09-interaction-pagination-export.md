# 09 筛选、分页、导出与通用交互

## 9.1 筛选与搜索

- 所有列表页支持**多条件组合筛选** + **名称类模糊搜索**（防抖 300ms 可选）。  
- 筛选条件变化时重置到**第 1 页**（与资源/项目空间分布等现有页一致体验）。

## 9.2 分页

- 默认 **每页 20 条**。  
- 支持切换：**10 / 20 / 50 / 100**（持久化到 `localStorage` 可选）。  
- 显示总条数、当前页、上一页/下一页；移动端可简化为「加载更多」（V2）。

## 9.3 导出

- 导出当前筛选结果：**Excel**（推荐 `.xlsx`）或 **CSV**（V1 可先 CSV）。  
- 列与当前表格列一致；大数据量走异步任务 + 下载中心（V2）。

## 9.4 删除

- 统一使用 **Modal 二次确认**：展示名称 + 不可恢复提示；确认后调用 `DELETE`；失败保留弹窗并提示原因。

## 9.5 状态标签（AI 能力）

| 状态 | 色标 |
|------|------|
| 在线 | 🟢 |
| 维护中 | 🟡 |
| 离线 | ⚫/灰 |

文案与色盲模式需后续无障碍增强（V2）。

## 9.6 表单通用

- 必填项标 `*`；提交前统一校验；字段级错误贴近控件展示。
