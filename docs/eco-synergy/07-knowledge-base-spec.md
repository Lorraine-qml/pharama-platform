# 07 知识库 — 功能与界面需求

## 7.1 功能清单

| 功能 | 说明 |
|------|------|
| 列表查看 | 按**类型**（公共/行业/私有）、**所属项目**筛选；`🔍 知识库名称` |
| 新增知识库 | 名称、类型、所属项目（私有必选）、描述；可选初始文档上传 |
| 编辑知识库 | 修改元数据；类型变更时校验所属项目 |
| 删除知识库 | 删除前检查**文档数**；若有文档则提示先清空或走归档策略 |
| 管理文档 | 跳转 `/eco/knowledge-base/:libraryId/manage` |
| 访问知识库 | 跳转只读「知识库详情」或弹窗内嵌文档列表（产品二选一） |

## 7.2 列表页布局（线框）

- 标题：`知识库` + `[+ 新建知识库]` `[导入]`（V2）  
- 筛选：类型、所属项目、搜索  
- 列：`知识库名称` | `类型` | `所属项目` | `文档数` | `最后更新` | `操作`  
- 操作：`[访问]` `[管理]`（按权限）

## 7.3 新建 / 编辑弹窗

| 字段 | 说明 |
|------|------|
| 知识库名称 | 必填 |
| 类型 | 单选：`公共` / `行业` / `私有` |
| 所属项目 | 私有库**必选**；公共/行业可为空或固定「-」 |
| 描述 | 选填 |
| 初始文档 | `选择文件`，支持多文件；V1 可仅 UI，实际上传接 OSS（见 10） |

## 7.4 文档管理子页（二级界面）

路径：`/eco/knowledge-base/:libraryId/manage`

- 顶栏：标题 `知识库管理 - {名称}` + `[返回]` + `[上传文档]` + `[搜索]`  
- 表格：`文档名称` | `类型` | `大小` | `上传时间` | `上传人` | `操作`（预览/下载/删除）  
- 删除：二次确认；私有库仅 owner / 运营可操作  

## 7.5 权限（库级 V1）

- 不做文档级 ACL；仅控制「能否进入某库的管理页」「能否删除库」。  
- 私有库与**入孵实体项目**绑定 `projectId`，项目方仅能访问绑定本项目之私有库。

## 7.6 接口（建议）

- `GET/POST/PUT/DELETE /api/eco/knowledge-bases`  
- `GET /api/eco/knowledge-bases/:id/documents`  
- `POST /api/eco/knowledge-bases/:id/documents`（multipart，OSS 回调）  
- `DELETE /api/eco/knowledge-bases/:id/documents/:docId`  

## 7.7 验收要点

- 删除库有文档时必须拦截并提示。  
- 私有库未选项目不可保存。
