# 05 外部合作 — 功能与界面需求

## 5.1 功能清单

| 功能 | 说明 |
|------|------|
| 列表查看 | 机构列表；按**类型**、**合作状态**、**名称**筛选；分页；导出 |
| 新增机构 | 表单 + 保存 |
| 编辑机构 | 预填表单 |
| 删除机构 | 二次确认 |
| 关联实体项目 | 下拉：入孵实体项目；表示业务往来对象 |
| 导入 | V1 可做模板下载 + 单行演示导入；V2 Excel 批量 |
| 详情 | 弹窗或侧拉：完整信息 + 关联项目 + 备注 |

## 5.2 列表页布局（线框）

- 标题：`外部合作` + `[+ 新增机构]` `[导入]` `[导出]`  
- 筛选：`类型`、`合作状态`、`🔍 机构名称`  
- 表格列：`机构名称` | `类型` | `联系人` | `电话` | `合作状态` | `关联实体项目` | `操作`  

## 5.3 新增 / 编辑弹窗字段

| 字段 | 控件 | 校验 |
|------|------|------|
| 机构名称 | 文本 | 必填 |
| 机构类型 | 下拉 | 必填：`CRO` / `医院` / `高校` / `检测机构` / `投资机构`（可扩展） |
| 联系人 | 文本 | 必填 |
| 联系电话 | 文本 | 必填 |
| 电子邮箱 | 文本 | 选填 |
| 合作状态 | 下拉 | `进行中` / `意向中` / `已结束` |
| 关联实体项目 | 下拉 | 首项「无」 |
| 备注 | 多行 | 选填 |

## 5.4 与基础数据同步

- **数据来源**：基础数据 → 名单管理（外部合作机构）应保持主数据一致；本模块可作为**孪生生态视角的快速编辑入口**，写入应同步或经审批回写主数据（架构二选一，推荐「单写主表 + 本模块调同一 API」）。  
- **V1**：允许本地演示表；文档约定与 `基础数据/名单管理` 的字段映射关系。

## 5.5 接口（建议）

- `GET/POST/PUT/DELETE /api/eco/external-partners`  
- `GET /api/eco/external-partners/:id`  
- `POST /api/eco/external-partners/import`（V2）  

## 5.6 验收要点

- 电话展示支持脱敏（列表）与完整（详情权限控制）。  
- 删除二次确认；导出字段与列表一致。
