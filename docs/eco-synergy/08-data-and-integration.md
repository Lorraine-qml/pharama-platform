# 08 数据来源与模块联动

## 8.1 总表

| 子模块 | 数据来源 | 说明 |
|--------|----------|------|
| 虚拟项目 | 入孵管理（入孵类型=虚拟）**或**独立 `eco_virtual_project` 表 | V1 可单独维护表；后续可双向同步入孵档案 |
| 外部合作 | 基础数据 → 名单管理（外部合作机构） | 推荐与主数据同源 API，避免双写不一致 |
| AI 能力 | AI 能力中台 | V1 静态 seed；V2 OpenAPI / 配置中心同步 |
| 知识库 | 独立知识库表 + OSS 对象索引 | 与资源运营解耦；可保留 `resourceId` 可选外链 |

## 8.2 关联实体项目（共用规则）

- 下拉选项：`GET` 入孵档案列表，过滤 `incubationType = 实体`（及在孵状态业务条件）。  
- 展示：`{projectName}` + `({creditCode 或 internalCode})`。  
- 解除关联：将 `linkedPhysicalProjectId` 置空；需校验是否影响合同（业务规则）。

## 8.3 与孪生、资源的关系

- **孪生台账**：不因虚拟项目写入而改变空间占用。  
- **资源运营**：知识库与资源目录不强制关联；若未来「文档即资源」再扩展关联表。
