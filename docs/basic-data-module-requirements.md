# 基础数据模块 — 完整需求说明（孵化运营平台 · 配置中心）

> 适用范围：孵化运营后台「基础数据」菜单下全部子模块。本文档承接产品概要，可作为研发、测试与运维审计的单一事实来源（SSOT）。

## 一、模块定位与原则

### 1.1 定位

基础数据模块是平台的**全局配置中心**，面向**系统管理员**与**运营管理员**，集中维护：

- 评价体系（维度、指标、权重、等级、评分公式）
- 合同模板（版本、占位符变量、生命周期）
- 专家库（档案、偏好、停用策略）及**项目–专家匹配规则**
- 名单（外部合作机构、项目来源类型、黑名单）
- 字典与标签（全站下拉口径）

上述数据被 **科创策源、入孵签约、资源运营、孵化评估** 等业务模块引用；**发布后全局生效**，需保证版本可追溯与权限受控。

### 1.2 核心原则

| 原则 | 说明 |
|------|------|
| 单向依赖 | 业务模块仅引用基础数据，不在业务内复制字典 |
| 版本与快照 | 已生效业务数据绑定「当时版本」，不因后续编辑回溯改写历史 |
| 软删除优先 | 专家、名单、字典项等有历史引用时宜软删/停用，避免破坏审计 |
| 操作可审计 | 关键写操作写入审计日志（谁在何时改了什么），满足合规 |
| 权限分级 | 见第八章 |

## 二、7.1 评价表管理

### 2.1 功能概述

用于配置各类评分规则：**项目评估 / 成长评分 / 资源评价**等，包含：

1. **评价维度 / 指标 / 权重 / 等级**：从哪些角度评、每项指标最高分、维度权重之和为 100%。
2. **评分规则配置**：对不同业务场景绑定**独立的计算公式**（如加权求和、自定义表达式）。
3. **版本**：每次保存生成新版本；仅**启用中**最新版本可被新业务引用；进行中评估继续使用旧版本快照。

### 2.2 界面信息架构

| 页面/区域 | 说明 |
|-----------|------|
| 评价表列表 | 筛选：适用场景、状态；搜索名称；表格列：名称、场景、版本、状态、最后修改、操作 |
| 维度配置 | 自列表「维度」进入：维度表 + 权重 + 下级指标列表；等级规则概要；✨ AI 推荐权重 |
| 评分规则 | Tab「评分规则」：规则名称、适用评价表、公式摘要、「编辑公式」|

### 2.3 操作与校验

| 操作 | 规则 |
|------|------|
| 新建评价表 | 弹窗：名称、适用场景（下拉：入孵初筛、成长评分、资源匹配…）；初始状态**草稿**，版本号 v1 |
| 编辑维度 | 可增删维度；权重之和须为 **100%**，否则阻断保存并提示 |
| 指标 | 每维度多条指标；每条：**名称 + 分值区间（如 0–10）** |
| AI 推荐权重 | 调用 **weight_suggester**：返回建议权重 + 可读理由；用户点「应用」写入表单（可改）|
| 等级规则 | 可配置多档名称与区间（如优秀 ≥85）；支持多套模板（按赛道/场景可选）|
| 公式编辑 | **维度得分 / 指标得分**为变量来源；运算符、常数、括号；保存前语法校验 |
| 启用 / 停用 | 仅「启用中」可被业务调用；停用后新项目不可选用 |

## 三、7.2 合同模板管理

### 3.1 功能概述

管理 **入孵协议、租赁协议、服务协议** 等模板；支持：

- **版本**：每次保存递增版本号，旧版本只读可查、可比对、可回滚（权限内）。
- **富文本**：在线编辑正文；插入 **占位符变量**（来自变量库）。
- **预览**：占位符替换为示例数据，查看渲染效果。
- **导入导出**：占位支持 .doc/.docx 导入解析、导出 Word/PDF（可与文档服务集成）。

### 3.2 占位符示例

如：`{{项目名称}}`、`{{信用代码}}`、`{{入孵开始日期}}`、`{{楼宇}}`、`{{租金}}` 等；需在「变量列表」可查说明。

### 3.3 AI 辅助

**contract_draft_generator**：输入入孵类型、园区条款偏好、风格（严谨/简洁）；生成草稿后落入编辑器，人工修订再保存新版本。

## 四、7.3 专家库管理

### 4.1 功能概述

维护评审/咨询专家的**基本信息、领域标签、评审偏好、履历**；支持与科创策源「分配专家」联动展示 **AI Top N 推荐**。

### 4.2 界面

| 页面 | 内容 |
|------|------|
| 专家列表 | 筛选：领域、状态；表格：姓名、单位、领域、评审次数、均分、状态、操作 |
| 专家编辑 | 表单：基本信息、多选领域、可评审阶段、响应时长与报酬口径、启用状态、简历附件 |
| 匹配规则 |  sliders/输入：**技术关键词匹配、阶段匹配、历史相似、地区、负载均衡** 五项权重之和 100%；✨ 「优化」调用历史满意度模型（占位）|

### 4.3 业务规则

- **删除**：软删除或归档；若存在**未完成评审任务**则禁止删除，需转移任务。
- **AI 匹配（业务侧调用）**：**expert_matcher** + 本地权重，输出排序、匹配度、理由话术。

## 五、7.4 名单管理

### 5.1 功能概述

统一管理三类 Tab：

1. **外部合作机构**：CRO/CDMO、医院、高校、投资方等。
2. **项目来源类型**：企业/高校/研究所/医院等业务枚举扩展。
3. **黑名单**：主体、拉黑原因、时间；停用后业务禁止选用。

### 5.2 通用能力

筛选、导入导出（Excel 模板）、启用/停用、软删除（黑名单删除二次确认）。

### 5.3 AI

当前无内置 AI；预留：根据履约数据推荐优质合作机构。

---

## 六、7.5 字典标签管理

### 6.1 功能概述

按「字典分组」维护全站下拉项，例如：**行业方向、项目阶段、研发阶段、资源类型、入孵类型、空间/资源状态** 等。

### 6.2 能力

- 分组列表 + 「管理标签」弹窗：**增删改、排序（拖拽占位）、启用/停用**。
- 删除校验：若有业务引用则改为**禁用**或提示不可删除（可配置策略）。
- 批量导入导出标签（Excel）。

### 6.3 生效机制

前端通过配置中心下发或刷新后重新拉字典；可选用 WebSocket/SWR 失效策略（本文档不关心具体技术选型）。

---

## 七、非功能与安全

### 7.1 日志与审计

所有写接口记录：**操作者、租户/园区、对象类型、对象 ID、变更 diff、终端/IP、时间戳**。

### 7.2 性能建议

字典与名单类接口可走缓存（短 TTL + 失效推送）；评价体系版本列表分页加载。

## 八、权限矩阵（节选）

| 角色 | 评价表 | 合同模板 | 专家库 | 名单 | 字典 | 删除预置项 |
|------|--------|----------|--------|------|------|-------------|
| 超级管理员 | 读写 | 读写 | 读写 | 读写 | 读写 | ✓ |
| 运营管理员 | 读写 | 读写 | 读写 | 读写 | 读写删非预置 | ✗ |
| 普通运营 | 只读 | 只读 | 只读 | 只读 | 只读 | ✗ |

*预置字典/系统内置分组可由 `isPreset` 标记；运营管理员仅能停用不可物理删除。*
